S1 adapts `ctx.files` to `MytFilePort` and composes the props. G2 implements `MytRepository`; G3 implements `useMytData(input: UseMytDataInput): MytViewModel`; G4 supplies `RankedActivity[]`; G5 supplies `ActivityPresence`; G9 uses `ActionState`. S3–S10 use their named prop interfaces. The full behaviour and folder layout are in Contract.md.

`paths.ts` imports `keyForId` and `planIdForActivity` from `./domain/identifiers`. S1 must import T3's proposal at that path before runtime integration. This dependency is deliberate and no alternate encoder is included. The other external helpers are not yet integrated.
