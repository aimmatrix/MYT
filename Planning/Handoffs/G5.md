## Exports and contract

- `MYT_PRESENCE_ROOM = "myt-v1"`.
- `useActivityPresence(route: Route, currentUser: CurrentUser | null): ActivityPresence`.
- `selectActivityViewers(peers, activityId, currentUserId): PresenceViewer[]`, a pure selector useful for focused checks.
- `PresenceStrip({ presence, mode, currentUser }: PresenceStripProps)`.

The hook imports Lightfern's documented React room hooks through S1's `host.ts`. It sends only `{ v: 1, screen, activityId }`, changes that payload with navigation, and clears it on unmount. Room hooks leave the room when their last consumer unmounts. It displays only peers whose validated payload says they are on the same activity screen. It rejects malformed payloads, sample/preview IDs and own-account tabs; it groups remaining views by `user.id`. The strip renders the current participant as “You” when appropriate, shows other real account names with local initials, and distinguishes disconnected, connected with no peers, and preview states. It does not write files or read persistent participant records.

## Integration

Mount the hook once in the live app composition with the current `Route` and `CurrentUser`, then pass its result to S5's `ActivityDetailProps.presenceStrip` as `{ presence, mode: "live", currentUser }`. Keep the hook's component unmounted in explicit preview mode so preview never joins a real room. `PresenceStrip` consumes the frozen G1 prop interface and S2's `myt-presence`, `myt-avatar-row` and avatar classes. S1's M0 probe already uses the same room; replace that probe when wiring the real App.
