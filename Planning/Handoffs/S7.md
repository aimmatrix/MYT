## Behaviour

- **Options**: one native radio per option, in S2's `myt-option` markup. Valid options come first in the parent's consensus order, then unavailable ones (disabled, "No longer available"). Title is `formatLondonTimeRange` when `endAt` exists, else `formatLondonDateTime`. Availability labels come from a three-entry local map (C5 is absent); unknown keys show nothing.
- **Counts and result line**: all from the supplied `consensus`. Bar width is `count / voterCount`, display only. A single leader reads "has the most votes so far, the organiser still chooses". A tie names the tied times and says the organiser decides. Zero votes says "No votes yet". Nothing says a time is agreed.
- **Who can vote**: live mode, signed in, `onSetVote` present, `myInterest` ready and `"interested"`, `myVote` ready, no plan. Otherwise a notice explains why: plan exists, preview, signed out, no callback, interest loading or error, not joined ("Join first to vote" with a **Go to interest** button calling `onGoToInterest`, or "Rejoin to vote" if withdrawn), vote loading or error.
- **Withdrawn with a saved vote**: the vote stays selected, tagged "Not counted", with an explanation. It is not moved.
- **Stale or invalid saved choice**: a warning names the time (or says it is no longer listed), says it is not counted, and offers **Clear my choice**. The radio for a still-listed unavailable option stays checked but disabled. Nothing is silently reassigned.
- **Saving**: one in-flight call at a time (a ref guard, so rapid clicks cannot double-submit). The chosen option shows as selected while saving, and a status line reads "Saving your choice…". Radios stay enabled during the save so focus is not lost; extra changes are ignored.
- **Success**: "Saved. You chose X. It can take a moment to show up for others." The saved choice stays shown until the `myVote` prop's option or `updatedAt` changes, so it does not flicker back to the old value while sync catches up.
- **Failure** (rejected promise, thrown error or `ok: false`): selection reverts to the last persisted choice, and a `role="alert"` notice shows the message with **Try again** for the same choice. A parent `actionState` of `error` renders the same notice and calls its `retry`.
- **Clear**: **Clear my choice** passes `null` (explicit clear), shown only when a valid choice exists.
- **Reset**: local state and any in-flight result are discarded when `activityId` or the current user changes.
- **Copy**: a standing line says a vote is not a booking or RSVP and the organiser confirms the time and place.
- No `<form>`, no inline colours (the only inline style is the bar width), no storage, host or presence access.
